# عباسی پبلیکیشن نیٹ ورک (APN)
## Inventory, Production & Warehouse Management ERP

بسم اللہ الرحمن الرحیم

عباسی پبلیکیشن نیٹ ورک کے پریس اور پروڈکشن یونٹ کے لیے تیار کردہ ایک مکمل لائیو ERP ڈیش بورڈ اور مینجمنٹ سسٹم۔ اس سسٹم کا مقصد خام مال کی خریداری سے لے کر کتب کی پرنٹنگ، بائنڈنگ، ڈیمیج کنٹرول اور ویئر ہاؤس تک کے تمام مراحل کو ایک ہی **کامن یونیک ٹریکنگ کوڈ (Job Card / Batch ID)** کے تحت جوڑنا ہے۔

---

## 🚀 فوری چلانے کا طریقہ (How to Run)

### طریقہ 1: مکمل لائیو سرور کے ساتھ چلانا (Recommended)
1. فولڈر میں موجود **`run_server.bat`** پر ڈبل کلک کریں۔
2. یہ خودکار طور پر سرور شروع کرے گا اور آپ کے براؤزر میں درج ذیل ایڈریس کھول دے گا:
   👉 **`http://127.0.0.1:8000`**
3. **موبائل یا پریس کے دوسرے کمپیوٹرز سے کھولنا:**
   اپنے وائی فائی کا IP ایڈریس دیکھ کر کسی بھی فون یا ٹیبلٹ پر کھولیں:
   `http://[آپ_کے_کمپیوٹر_کا_IP]:8000`

### طریقہ 2: فوری آف لائن موڈ (Instant Offline View)
اگر آپ کو فوری طور پر ڈیش بورڈ، رپورٹس یا انٹری دیکھنی ہو تو بغیر سرور کے صرف **`open_dashboard.bat`** پر ڈبل کلک کریں یا `frontend/index.html` کو کسی بھی براؤزر میں اوپن کر لیں۔

## 📋 سسٹم کے اہم ماڈیولز اور ورک فلو (Workflow Stages)

```
خام مال اسٹور (Paper/Card/Ink)
      ⬇️ (BOM کٹوتی)
ورک آرڈر کا اجرا (یونیک جاب کوڈ تفویض)
      ⬇️
-----------------------------------------
| 1. انر پرنٹنگ (فارمے)   | 2. آؤٹر (ٹائٹل کور) |  ⬅️ (ایک ہی کامن کوڈ کے تحت)
-----------------------------------------
      ⬇️
بائنڈنگ اسمبلی (دونوں کا ملاپ & تھری نائف کٹنگ)
      ⬇️ (ڈیمیج لاگ)
فنش گڈز ویئر ہاؤس (ریک و شیلف میں داخلہ)
```

### 1. خام مال اسٹور (Raw Materials Store)
* انر ٹیکسٹ پیپر (سائز: 23x36, 20x30, وغیرہ، GSM: 68, 70, 80)
* کور کارڈ (260 GSM Art Card, 300 GSM Bleached Board)
* پرنٹنگ سیاہی (CMYK: Cyan, Magenta, Yellow, Black)
* لیمینیشن رولز (Gloss / Matt) اور بائنڈنگ گلو (Hot melt glue)
* **کم اسٹاک ایمرجنسی الرٹ (Red Alert):** جب بھی ریم یا کلوگرام کم از کم حد سے کم ہوں گے، ڈیش بورڈ پر فوری سرخ الارم آ جائے گا۔

### 2. کتب ماسٹر اور بل آف مٹیریل (Book Master & BOM)
* ہر کتاب کا یونیک آرٹیکل کوڈ (مثلاً `APN-BK-0101`)۔
* صفحات کا اندراج کرتے ہی سسٹم خود بتائے گا کہ کتنے **فارمے (Forms)** بنتے ہیں (16 صفحات کا ایک فارما)۔
* پری کاسٹنگ اور فی کتاب خام مال کی کھپت (BOM)۔

### 3. ورک آرڈر اور پرنٹ ایبل جاب کارڈ (Work Order & Job Card)
* پروڈکشن جاب کا اجرا (مثلاً 5,000 کاپیاں)۔
* سسٹم خود بخود **یونیک ٹریکنگ جاب نمبر (Unique Tracking ID)** تفویض کرتا ہے (مثلاً `APN-WO-2026-0001`)۔
* **پرنٹ ایبل جاب کارڈ (Job Card with Barcode):** اس کارڈ پر لائیو بارکوڈ، کتاب کی تفصیل، اور پریس ورکرز کے دستخط کا ٹیبل چھپتا ہے جو پرنٹنگ پیلٹ کے اوپر لگتا ہے۔
* خام مال اسٹور سے مطلوبہ پیپر اور کارڈ خودکار طور پر خارج ہو جاتا ہے۔

### 4. پروڈکشن فلور مانیٹرنگ (Floor Monitoring)
* **انر پرنٹنگ سیکشن:** انر کے فارموں کی چھپائی اور مس پرنٹ کی تعداد درج کرنا۔
* **کور پرنٹنگ سیکشن:** ٹائٹل کارڈ کی چھپائی اور لیمینیشن کا لاگ۔
* **بائنڈنگ سیکشن:** دونوں کا ملاپ، فنشنگ، اور بائنڈنگ نقص کا الگ حساب۔

### 5. فنش گڈز گودام (Finished Goods Warehouse)
* تیار کتابیں اسی جاب کوڈ کے ساتھ گودام منتقل ہو جاتی ہیں۔
* ریک اور شیلف نمبر کی الاٹمنٹ (مثلاً `Rack-A / Shelf-02`)۔

### 6. ڈیمیج و ویسٹیج لاگ (Damage & Financial Loss)
* پرنٹنگ، لیمینیشن اور بائنڈنگ میں ضائع ہونے والے مواد اور کتابوں کا مالیاتی تخمینہ (روپوں میں) تاکہ ماہانہ نقصان کنٹرول کیا جا سکے۔

## 🛠️ تکنیکی تفصیلات (Tech Architecture)
* **Backend:** Python FastAPI + SQLAlchemy + SQLite (`backend/apn_database.sqlite`)
* **Frontend:** Modern Responsive Single Page App (Tailwind CSS, Lucide Icons, Bilingual Urdu/English Nastaliq font)
* **API Documentation:** `http://127.0.0.1:8000/docs` (خودکار انٹرایکٹو Swagger API ٹیسٹر)
